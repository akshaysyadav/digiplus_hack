# Components Directory

Reusable UI components for the React frontend:

- `PrecedentCard.jsx`: Displays historical ticket match, similarity %, and historical resolution.
- `ConfidenceBadge.jsx`: Visual indicator for similarity/confidence score (High / Medium / Low).
- `DecisionIndicator.jsx`: Badge for AUTO RESOLVE vs HUMAN REVIEW routing.
- `ActionSimulationCard.jsx`: Displays simulated action details (refund, redelivery, coupon).
- `DraftReplyEditor.jsx`: Editable drafted customer response text area.
- `ExplanationPanel.jsx`: Visual "Why this action?" audit explanation view.
- `OrderContextCard.jsx`: Panel displaying order status, item breakdown, and total value.
